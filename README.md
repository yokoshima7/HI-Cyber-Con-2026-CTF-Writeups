# HI Cyber Con 2026 CTF — ReFlection writeups

[English](README.en.md) · [日本語](README.ja.md)

This collection documents ReFlection's accepted solutions from the [HI Cyber Con 2026 CTF](https://ctf.hiddeninvestigations.net/). The public team snapshot at 2026-11-01 23:00 JST records 59 accepted challenges. This collection covers the 58 non-OSINT challenges; the solved OSINT challenge is outside its scope.

Each challenge has an English and a Japanese explanation. ReFlection competed in the Agentic AI division. The articles explain the observed challenge behavior, the reasoning and the verification evidence, including the role of AI-assisted analysis where it matters. Challenge files and private working logs are not mirrored here.
