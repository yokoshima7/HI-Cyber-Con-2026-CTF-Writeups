The official `ground-station.zip` SHA-256 is `21eecb59a1d0559081a7aaf53abc2e8187178dd4d667279906932dde4a574a19`. It contains an x86-64 firmware image, a maintenance client, and the GSP/1.0 protocol reference. The controller will run a fueling test only after engineer authentication and a safe, trusted ladder program.

## Authentication

The provided client did not calculate the engineer response. Disassembly of the firmware recovered a 16-byte key generated by a 32-bit LCG seeded with `0x1f2e3d4c`. Each step uses multiplier `0x19660d`, increment `0x3c6ef35f`, and emits `((state >> 17) XOR (index * 0x5b)) & 0xff`. Parse the resulting key as four little-endian 32-bit words `a,b,c,d`, and the eight-byte session nonce as `n0,n1`. Repeat the following twelve times, with all additions modulo 2³²:

```text
a = ROL(a + n0, 7)
b = ROL(b XOR a, 11)
c = ROL(c + b + n1, 17)
d = ROL(d XOR c, 19)
n0 = n0 + d + round * 0x9e3779b9
n1 = ROL(n1 XOR a, 13)
(a,b,c,d) = (b,c,d,a)
response = LE32(a XOR c) || LE32(b XOR d)
```

A local emulation of the supplied machine code matched our implementation for the firmware's fixed vector and three additional nonces. We used that recovered response for `AUTH` on our own instance.

## Repair

The reference requires `INTERLOCK_OK` only when tank temperature is at most 45 °C and pressure at most 100 kPa. `PROG LIST` and `BACKUP GET` showed the same defect in both live and backup programs: temperature was compared against **145**. The other rungs matched the reference. With the watchdog enabled, changing only the live program would be restored or rejected at test arm. We performed and verified:

```text
PROG SET INTERLOCK_OK (TANK_TEMP <= 45) AND (TANK_PSI <= 100)
BACKUP SAVE
BACKUP STATUS
WDOG STATUS
RUNTEST
```

The first two commands corrected the live rung and saved it as the trusted backup. `BACKUP STATUS` then showed matching live, backup, and trusted checksums, with `arm_will_restore=0`; the watchdog remained enabled. One `RUNTEST` reported `SUCCESS reason=fill_target_reached_scan_51` and the flag. A separate `STATUS` readback showed `solved=1` and the same flag. The official challenge UI accepted it.

Flag: `hiCTF{ground_station_fueling_test_nominal_f43b56f7e6}`

The key lesson is to check the backup and watchdog contract alongside the ladder logic. AI-assisted disassembly identified the access routine; direct machine-code emulation, service readback, and official acceptance provided independent checks.
